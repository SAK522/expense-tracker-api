      How it works

      Simple on the outside. Secure underneath.

      01

      Every entry is yours alone

      Each request carries a secure login token. The server only ever reads or changes entries that belong to that token's owner.

      02

      Totals come from the database

      Your monthly income, spending and balance are calculated by the database in one step, using exact decimal amounts, so paise never drift.

      03

      Bad input is stopped at the door

      Negative amounts, impossible dates or empty categories are rejected before they reach your ledger, with a clear message.

      Built by T. Sakthi with FastAPI, PostgreSQL and JWT authentication.Free hosting: the first request after a quiet spell can take up to a minute.
